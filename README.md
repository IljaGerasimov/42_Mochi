This Project was created in under 2 Days and features a Browser/Website Extension for the 42Intra Profile Page, that allowed students to adopt their own little Tamagotchi that they would have to care for by actively showing up and tracking log time. If the user was inactive for a longer period of time without notice the "Mochi" would gradually starve and die. The Mochi featured different colors (Pink, Purple and Green) and students could interact with it and feed it different food.
